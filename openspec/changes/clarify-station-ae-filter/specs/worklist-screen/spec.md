# Spec Delta

## Purpose

Web 画面のワークリストで、予約を取得し、選び、選んだ予約を取得し直す操作と、
失敗したときに利用者へ出す知らせを定める。

## ADDED Requirements

### Requirement: 装置の AE タイトルの絞り込みをそれと分かる言葉で示す

ワークリストの画面は、Scheduled Station AE Title (0040,0001) の検索条件を
「装置の AE タイトル」というラベルと、「この装置の AE タイトルで絞る（<自分の AE
タイトル>）」「絞らない」の選択肢で表示しなければならない（SHALL）。既定は
「この装置の AE タイトルで絞る」とし、選ぶと Scheduled Procedure Step Sequence の
中の (0040,0001) に自分の AE タイトルを入れて送る（PS3.4 K.6.1.2.2、IHE RAD TF-2
Table 4.5-2）。

#### Scenario: 既定の条件で取得する

- **WHEN** 自分の AE タイトルが `DTG_CT01` の画面で、ワークリストの画面を開いて「ワークリストを取得」を押す
- **THEN** 条件の欄に「装置の AE タイトル」「この装置の AE タイトルで絞る（DTG_CT01）」と表示され、C-FIND の Scheduled Procedure Step Sequence の (0040,0001) に `DTG_CT01` が入る

#### Scenario: 絞らないで取得する

- **WHEN** 利用者が「絞らない」を選んで「ワークリストを取得」を押す
- **THEN** C-FIND の (0040,0001) は長さ 0 で送られ（全ての値に一致）、別の装置の予約には「別の装置」の印が付く

### Requirement: 予約の詳細に予定の装置の AE タイトルを分けて示す

予約の詳細のパネルは、予約の Scheduled Station AE Title (0040,0001) を「予定の
装置の AE タイトル」の行に、予定日時・モダリティとは別に表示しなければならない
（SHALL）。値が空なら「—」を表示する。

#### Scenario: 詳細を開く

- **WHEN** 利用者が (0040,0001) が `DTG_MR01` の予約の行を選ぶ
- **THEN** 詳細のパネルに「予定の装置の AE タイトル」の行があり、値は `DTG_MR01` で、「予定」の行には予定日時とモダリティだけが表示される
