# Spec Delta

## ADDED Requirements

### Requirement: 取得の通信失敗と認証切れを一覧の場所に出す

ワークリストの取得と「取得し直す」が通信で失敗したときは、一覧の場所
（`#results`）にエラーの知らせを出さなければならない（SHALL）。401 の場合も
同じ場所にログインの知らせを出し、生の応答では差し替えない。

#### Scenario: ワークリストの取得が届かない

- **WHEN** 「ワークリストを取得」の通信が失敗する
- **THEN** 一覧の場所に接続を確かめてもう一度押すよう知らせる

#### Scenario: 取得し直す要求の認証が切れる

- **WHEN** 「取得し直す」の応答が 401 になる
- **THEN** 一覧の場所に頁を読み込み直してログインし直すよう知らせる
