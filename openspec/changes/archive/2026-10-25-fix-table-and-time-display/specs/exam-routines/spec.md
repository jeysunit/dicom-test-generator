# Spec Delta

## ADDED Requirements

### Requirement: 押せない「外す」の理由をキーボードにも届ける

撮影の画面は、撮影の対象の最後の1行の「外す」を、`disabled` ではなく `aria-disabled="true"`
にし、押しても何も起こさず、理由「最後の1行は外せません」を `aria-describedby` で結んだ
見えない文で示さなければならない（SHALL）。画面に説明の文は足さない。

#### Scenario: 最後の1行

- **WHEN** ルーチンの行を残り1行まで外し、その行の「外す」に Tab で移る
- **THEN** ボタンにフォーカスが止まり、読み上げに「最後の1行は外せません」が結ばれ、押しても行は外れない

### Requirement: ルーチンの表は狭い画面でも枠の中ではみ出さない

撮影の画面のルーチンの表は、幅 390px 前後の画面でも、表の枠の中で横にはみ出さない幅に
しなければならない（SHALL）。右端の「外す」「戻す」を押しても、表が横に動かない。

#### Scenario: 狭い画面で右端のボタンを押す

- **WHEN** 幅 390px の画面で、ルーチンの表の右端の「外す」を押す
- **THEN** 表の枠は横にスクロールせず、先頭の「シリーズ」の列は切れない

### Requirement: 撮影の応答の後は結果の場所へフォーカスを移す

撮影の画面は、撮影の応答が返ったら、フォーカスを結果の場所（`#result`）へ移さなければ
ならない（SHALL）。押したボタンは応答まで押せず、フォーカスが本文の先頭へ落ちるため。

#### Scenario: キーボードで撮影する

- **WHEN** キーボードで「撮影」を押し、応答が返る
- **THEN** フォーカスは結果の場所にあり、結果の知らせが読み上げられる
