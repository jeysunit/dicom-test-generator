# ADR-0023: 名乗る装置を設定に複数書き、画面と CLI で切り替える

- 状態：採用
- 作成日：2026-10-23
- 最終更新日：2026-10-25

## 背景

DTG はモダリティの代わりをするが、自分の AE タイトルと Station Name は設定に1つ
（`modality.ae_title`・`modality.station_name`）しか書けず、変えるには設定ファイルを
書き換えて画面を再起動する必要があった。RIS・PACS のテストでは、CT の装置と MR の
装置のように、複数の装置からの検査を続けて作りたい。

決める必要があったのは、次の4点である。

- 装置をどう書き、どこで選ぶか
- 選んだ装置を、画面と CLI のどちらが、どこまで共有するか
- 切り替える前に作った送信・MPPS・保管確認を、どの AE タイトルで続けるか
- 画像の Station Name (0008,1010) を、装置・病院テンプレート・装置プロファイル・
  テンプレートのどの値にするか

PACS・RIS は、登録していない Calling AE Title からの Association を、
A-ASSOCIATE-RJ の理由 3「calling-AE-title-not-recognized」で拒否できる（PS3.8
9.3.4）。

## 決定

1. **装置は設定の `modality.stations:` に書く。** 1台ごとに表示名・AE タイトル・
   Station Name を書き、`modality.default_station` で既定を選ぶ。表示名と AE
   タイトルは重複させない。今の `ae_title`・`station_name` だけの設定は、装置1つの
   一覧として読む。理由：今の設定を書き換えずに動かすため
2. **選んだ装置は、状態の保存先（`state_dir/station.json`）に記録し、画面と CLI が
   同じ記録を使う。** 画面は上の帯の接続の状態で切り替え、CLI は `--station <表示名>` でその
   コマンドだけ別の装置にする（記録は変えない）。理由：実機のモダリティの「この
   装置」と同じく、画面と CLI で名乗る装置が食い違わないようにするため
3. **撮影と送信は、始めたときの装置の AE タイトルで最後まで行う。** 撮影は始めた
   ときの装置を写してから進め、送信は件に AE タイトルを記録してから送るので、途中で
   切り替えても名乗りは変わらない。あわせて、画面のプロセスの中で撮影が走っている
   ときと、送信中の件があるときは、切り替えを断る（利用者が切り替わったと思い込まない
   ように）。別のプロセスの CLI で走っている撮影は数えない（記録が名乗りを固定する
   ので、名乗りの食い違いは起きない）
4. **送信キューの件・MPPS の行・保管確認の要求は、作ったときの装置の AE タイトルを
   記録し、再送や結果の照合にその AE タイトルを使う。** 画像を送るときは、画像を
   作った装置（画像の Source Application Entity Title が設定の装置のどれか）の AE
   タイトルで名乗る。理由：MPPS の送信先を行に固定するのと同じく（ADR-0020）、あとで
   切り替えても、画像・MPPS・送信の名乗りをそろえるため
5. **保管確認の結果は、設定のどの装置の AE タイトルあてでも受け、要求を送った装置
   あてのものだけをその要求の結果にする。** ほかの AE タイトルあての Association は
   理由 7「called-AE-title-not-recognized」で拒否する
6. **画像の Station Name は、装置の Station Name を最初にする。** 空なら今までの順
   （病院テンプレート → 装置プロファイル → テンプレート）。理由：Station Name は
   「その画像を作った機械の名前」（PS3.3 C.7.5.1）で、装置の切り替えが表すものと
   同じだから
7. **相手が理由 3 で拒否したら、使った AE タイトルと、相手の側に登録が要ることを
   知らせる。**

## 検討した選択肢

- 選んだ装置を画面のプロセスの中だけで覚える：再起動で元に戻り、CLI と画面で名乗る
  装置が食い違う
- 装置ごとに既定のテンプレートや送信先を結び付ける：テンプレートと装置プロファイル
  は撮影の画面で選べるので、今は要らない。装置の一覧を細かくするほど、設定の誤りが
  増える
- 装置ごとに別の待ち受けのポートを持つ：1つの待ち受けで、呼ばれた AE タイトルを
  確かめれば足りる
- 再送のときに、いまの装置の AE タイトルで名乗る：切り替えた後の再送が、作ったとき
  とは別の装置からの送信になり、相手の記録と合わなくなる

## 結果

- 画面の接続の状態で装置を切り替えるだけで、CT と MR の検査を続けて作れる
- 送信キューと MPPS の待ち行列、保管確認の要求に AE タイトルの列が増える。前の版の
  行は、既定の装置の AE タイトルで埋める
- 使う装置の AE タイトルを、すべて PACS・RIS に登録する必要がある。登録していない
  ときは、拒否の理由を知らせる
