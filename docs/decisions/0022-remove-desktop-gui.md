# ADR-0022: PySide6 のデスクトップ画面を削除し、ファイルの作成は CLI に任せる

- 状態：採用
- 作成日：2026-10-22
- 最終更新日：2026-10-22

## 背景

PySide6 のデスクトップ画面（`app/gui/`）は、ADR-0011 で案 B（後で削除する）に
決まってから凍結している。案 B の削除の条件は「今の PySide6 の画面でできる作成が、
Web 画面でもできること」だったが、Web 画面でできるのは予約または予約の無い患者
からの撮影だけで、Job YAML や `quick` に相当する作成の画面は無い。

一方で、デスクトップ画面でできること（患者・テンプレート・シリーズ・出力先を
選んで DICOM ファイルを作成する）は、CLI の `generate`・`quick` ですべてできる。
画面を残すと、PySide6（大きなパッケージ）と pytest-qt を依存に持ち続け、CI でも
Qt のためのシステムライブラリと offscreen の設定を保守することになる。

## 決定

1. デスクトップ画面（`app/gui/`）と画面のテスト（`tests/gui/`）を削除する。
   利用者の操作は CLI と Web 画面で行う
2. DICOM ファイルの作成は CLI（`generate`・`quick`）に任せる。ADR-0011 の
   「既存の PySide6 の GUI の扱い」の削除の条件（Web 画面でも同じ作成ができる
   こと）は、この ADR で「CLI で同じ作成ができること」に置き換える
3. 依存から PySide6 と pytest-qt を削除し、CI から Qt のための設定を削除する
4. ADR-0003（PySide6 GUI）と ADR-0006（GUI の非同期処理）は、画面と一緒に役目を
   終えるので、置き換え済みにする
5. Web 画面にファイルの作成の画面を追加するかは、この ADR では決めない
   （roadmap の未実装に置く）

## 検討した選択肢

- **Web 画面に作成の画面を作ってから削除する（ADR-0011 の案 B のまま）**：
  画面を作るまで、PySide6 と Qt の CI の設定を保守し続けることになる。
  デスクトップ画面でだけできることは無いので、待つ理由が無い
- **凍結したまま残す**：依存と CI の設定が残り続け、画面が2種類ある状態が続く

## 結果

- 依存が減り、CI でシステムライブラリをインストールする手順が無くなる
- `python -m app.gui` は使えなくなる。ファイルの作成は
  `python -m app.cli generate`・`quick` で行う
- `docs/spec/05_gui.md` は欠番の文書にする。ADR-0006・ADR-0011 の本文が
  このファイルへリンクしているので、ファイル名は変えない
