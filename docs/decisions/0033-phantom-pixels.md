# ADR-0033: 図形の画素は、患者座標で評価した幾何学の図形にし、偽物と分かる文字を焼き込む

- 状態：提案
- 作成日：2026-10-27
- 最終更新日：2026-10-27

## 背景

画素の方式は `simple_text` と `ct_realistic`（[ADR-0005](0005-pixel-modes.md)）の
2つで、どちらも1つのシリーズの全画像が同じ絵になる。PACS のビューアでスライスを
送っても、位置が動いたことが画像から分からない。部位とも結び付かないので、頭部の
検査と胸部の検査が同じ絵になる。

一方、DTG の画素は合成したもので、臨床には使えない（project_charter の 1 章）。
それらしい画像に近づけるほど、本物の画像と取り違えられやすくなる。

## 決定

1. 画素の方式に `phantom`（図形）を足す。各画素の患者座標で3次元の図形を評価する。
   軸位・冠状断・矢状断は同じ Frame of Reference の同じ図形の断面になり、スライスの
   位置が変われば断面の大きさが変わる
2. 基本の図形は回転楕円体1つと、シリーズの中の番号で角度を変える位置の目印にする。
   ルーチンに部位（`phantom`）を書けば、部位の図形（楕円体・楕円柱・円柱・直方体と
   その殻の組）にする
3. 図形は区分ごとに一定の値で描き、ノイズ・ぼかし・臓器や骨の輪郭を描かない
4. どの画像にも、上端の帯に `TEST / SYNTHETIC`・患者 ID・検査日・何枚目か・位置を、
   画素の値の最小と最大だけで焼き込む。Burned In Annotation (0028,0301) は `YES`、Recognizable
   Visual Features (0028,0302) は `NO` にし、Image Comments に
   `SYNTHETIC TEST IMAGE - NOT FOR DIAGNOSIS` を書く（PS3.3 C.7.6.1）
5. 既定の方式は `ct_realistic` のままにし、`phantom` は Job・CLI・設定で選んだとき
   だけ使う

## 検討した選択肢

- 今の方式のまま、シリーズの中の番号の文字だけを描く：作りは小さいが、MPR や
  スライスを送る試験で、断面の大きさの変化を見られない
- 公開のファントムや実の画像を加工して使う：本物らしくなりすぎ、偽物と分からない。
  ライセンスの確かめも要る
- 既定を `phantom` に変える：今の Job と試験の画素が変わる。利用者が選ぶまで変えない
- 焼き込みを `TEST / SYNTHETIC` だけにして Burned In Annotation を `YES` にする：
  `YES` の定義（患者と撮影日を識別できる文字）に合わない

## 結果

- スライスを送ると図形が変わり、どの画像も帯の文字で偽物と分かる
- 焼き込みに患者 ID と検査日が入る。患者は架空なので、実の個人の情報は出ない
- 画素の方式が3つになり、spec/02・06・07 と CLI の選択肢が増える
- 文字は Pillow の既定のフォントで描くので、日本語は描かない

## 決めないこと

- PET の画素（PT のシリーズは今の画素のまま）
- US の画像
